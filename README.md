# Atlas Dash

A virtual real-time race across a regional map. Win short minigames to unlock the next region and collect cards to boost yourself or sabotage opponents. First map: Indonesia (Sabang → Merauke).

- Requirements: [`docs/requirements.md`](docs/requirements.md)
- Stack: three.js + TypeScript + Vite, HTML/CSS for 2D minigames, Colyseus for multiplayer (post-MVP), Vitest + Playwright.
